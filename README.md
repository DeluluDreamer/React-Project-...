# CampusLite — Simple React Student Portal

## Run
1. Extract the ZIP.
2. Open the `Simple-React-Student-Portal` folder in VS Code (the folder containing `package.json`).
3. Open Terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the Local URL shown by Vite.

## Netlify
Build command: `npm run build`
Publish directory: `dist`

## Concepts shown
React components and props, useState, useEffect, useRef, useContext, useReducer, conditional/list rendering, custom hook, React Router DOM, nested routing, useParams, useSearchParams, CRUD, form validation, responsive UI.
Note: This beginner-friendly version uses local sample data; it does not connect to an external API or Redux.
